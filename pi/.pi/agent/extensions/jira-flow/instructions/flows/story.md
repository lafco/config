# Fluxo selecionado: Story

A issue é uma Story. Não trate a issue como Epic e não invente um conjunto de filhos. Entenda o valor esperado, valide critérios de aceite e quebre somente o trabalho necessário para implementar a história. A entrega pode conter uma ou mais tarefas técnicas, mas todas devem estar diretamente ligadas à Story.

Use o vocabulário do time nas tarefas: `Codificação [BACKEND]` / `Codificação [FRONTEND]`, `Defeito`, `Execução de TU`, `Merge`. Não abra tarefa para etapa interna que caiba no mesmo commit.
